Problem Statement:
First-year students often experience decision paralysis when choosing a technology specialization 
(e.g., AI/ML, Web Development, Cybersecurity, Data Science, UI/UX, or Cloud & DevOps) due to an overload of unstructured information and a lack of personalized guidance. Without early direction, students risk spending time on misaligned learning paths, missing critical skill-building windows, and experiencing lower career confidence.

Target Audience & Utility: 
Designed for novice tech students struggling with specialization paralysis. This interactive Python tool provides immediate clarity by mapping individual preferences to tech tracks like AI/ML, Web Dev, and Cybersecurity. Architecturally, it highlights the power of conditional logic and interactive CLI/GUI design in turning basic user inputs into personalized, data-informed outputs.

Future Scope & System Roadmap
1.	Data Management: Implement persistent storage (SQLite/PostgreSQL) to maintain user session state, track assessment trends, and record longitudinal progress.
2.	Algorithmic Refinement: Replace standard conditional statements with weighted multi-criteria decision models or ML classifiers for refined suitability scoring.
3.	User Experience (UI/UX): Develop a GUI (PyQt/Tkinter) or web interface to enhance visual navigation and interactive feedback.
4.	Integration & Deliverables: Integrate external learning APIs (Coursera/Udemy) for targeted course mapping and enable automated PDF/Excel report exports.
